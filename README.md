# 📡 Projeto API - Gerador de Usuários

## 🎯 Descrição

Este projeto consiste em uma aplicação web que consome a API pública Random User, utilizando PHP no back-end para realizar requisições HTTP e retornar os dados em formato JSON.

Os dados são exibidos no front-end com HTML, CSS e JavaScript, permitindo interação do usuário por meio de filtros e buscas.

---

## 🚀 Funcionalidades

* 🔄 Geração de usuários aleatórios
* 🔍 Busca por nome
* 🎯 Filtro por idade
* 👤 Filtro por gênero
* 🌎 Filtro por país (nacionalidade)
* 🔢 Seleção da quantidade de usuários
* 🖼️ Exibição de imagem, nome, email, localização e idade
* ⚠️ Tratamento de erros na comunicação com a API
* 📱 Layout responsivo

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3 (puro, sem frameworks)
* JavaScript (Fetch API)
* PHP (consumo da API)

---

## 🌐 API utilizada

* Random User API
  https://randomuser.me/api/

## ▶️ Como executar o projeto

1. Instalar um servidor local (ex: XAMPP)
2. Colocar a pasta do projeto dentro de `htdocs`
3. Iniciar o Apache
4. Acessar no navegador:

```
http://localhost/projeto-api/
```

---

## ⚠️ Observações

Este projeto utiliza PHP no back-end, portanto não pode ser executado diretamente no GitHub Pages, que suporta apenas aplicações front-end.
